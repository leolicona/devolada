## Decisions *(mandatory)*

Each decision gets a stable identifier, is cited from elsewhere as `<feature-slug> D<n>`,
and records **the alternative that was rejected and why**. Code records what was built and
never what was refused; this section is the only place that survives.

- **D1 — [the decision, as a claim].** Rejected: [the alternative], because [reason].
- **D2 — …**

A decision is amended in place with a date when reality changes it. It is never deleted:
a rejected alternative that vanishes gets proposed again.
